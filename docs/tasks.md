# Tasks & Masking Module (`masters.tasks`)

The `masters.tasks` module implements controlled synthetic data masking, evaluation metrics, and task specifications for benchmarking LLMs on tabular data problems.

## Motivation

To objectively assess whether code generated by an LLM properly solves a data cleaning problem, ground truth is required. By taking a clean tabular dataset and synthetically injecting missing values under known statistical mechanisms, we obtain exact ground truth against which reconstruction quality can be computed mathematically.

## Public Interface

### 1. Synthetic Missingness Injectors (`masters.tasks.masking`)

* `inject_mcar(df, rate, columns=None, seed=None) -> (masked_df, mask)`:
  Injects Missing Completely at Random (MCAR) values, where each element has an independent probability `rate` of being masked.
* `inject_mar(df, target_col, cond_col, rate, seed=None) -> (masked_df, mask)`:
  Injects Missing at Random (MAR) values, where missingness in `target_col` depends on the values of `cond_col`.
* `inject_mnar(df, target_col, rate, seed=None) -> (masked_df, mask)`:
  Injects Missing Not at Random (MNAR) values, where probability of missingness depends on the value of `target_col` itself (upper tail censoring).

### 2. Evaluation Metrics (`masters.tasks.metrics`)

* `compute_nrmse(ground_truth, imputed, mask) -> float`:
  Computes Normalized Root Mean Squared Error strictly over the masked positions:
  $$\text{NRMSE} = \frac{\sqrt{\frac{1}{|M|} \sum_{(i,j) \in M} (X_{ij} - \hat{X}_{ij})^2}}{\sigma(X_M)}$$
* `compute_categorical_accuracy(ground_truth, imputed, mask) -> float`:
  Computes exact match accuracy across masked categorical cells.

### 3. Task Classes (`masters.tasks.imputation`)

* `ImputationTask`:
  Encapsulates dataset metadata, generates structured prompts requesting an `impute_missing(df)` function, and validates returned DataFrames against data invariants (shape, schema, remaining NaNs) before scoring quality with NRMSE.

## Example Usage

````python
from masters.tasks import ImputationTask, inject_mcar
import pandas as pd

clean_df = pd.DataFrame(
    {
        "age": [25.0, 40.0, 35.0, 50.0],
        "income": [50000.0, 90000.0, 75000.0, 110000.0],
    }
)

masked_df, mask = inject_mcar(clean_df, rate=0.25, seed=42)

task = ImputationTask(
    task_id="demo_01",
    dataset_name="synthetic",
    clean_df=clean_df,
    masked_df=masked_df,
    mask=mask,
    mechanism="MCAR",
    rate=0.25,
)

prompt = task.generate_prompt()
evaluation = task.evaluate_output(clean_df)
print("Data valid:", evaluation.data_valid)
print("NRMSE score:", evaluation.quality_score)
````
